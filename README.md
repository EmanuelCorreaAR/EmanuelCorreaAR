### Sobre mí

Software Engineer full stack, con foco en backend, sistemas y arquitectura de software.

Actualmente trabajo en **Naranja X**, dentro del squad **Help Experience**, desarrollando el **Hub de Eventos**: una plataforma interna que centraliza eventos de clientes y permite consultar, procesar y disparar comunicaciones en tiempo real.

Mi trabajo diario está principalmente alrededor de **Node.js, TypeScript, Angular y AWS**.

Fuera del producto, me interesa explorar cómo construir software **más explícito, reproducible, observable y confiable**, especialmente en sistemas donde una decisión de software puede terminar produciendo un efecto real.

### Proyectos destacados

- **RupuBoundary** — límites seguros entre decisiones probabilísticas y efectos deterministas. Contratos explícitos, freshness, optimistic concurrency control y adaptadores para distintos backends.
- **RupuSonda** — CLI local para inspeccionar, normalizar y reproducir señales IoT mediante un modelo canónico de eventos.
- **RupuData** — tooling para inspección y auditoría reproducible de datasets utilizados en sistemas de IA.
- **RupuContext** — herramientas para analizar y auditar el contexto que consumen sistemas basados en LLMs.

También exploro áreas como **software de alta confiabilidad, flight software, computación cuántica y seguridad**, principalmente como espacios de aprendizaje técnico y open source.
